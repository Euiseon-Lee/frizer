# FR!ZER

최초 작성일: 2026-09-13. 최종 갱신일: 2026-11-22.

**프리!저 · FR!ZER — 쪼코와 함께하는 1인 가구 식량 재고 관리**

음식을 등록하고 실온·냉장실·냉동실에 남은 재고를 확인하는 모바일 웹입니다.
최소한의 입력으로 재고를 정리하고, 먼저 확인할 음식을 찾는 데 도움을 줍니다.

## 주요 기능

- **음식 등록**: 새 음식과 추가 구매를 구분해 등록하고, 엑셀로 여러 항목을 한 번에 등록합니다.
- **보관 정보 관리**: 위치·기한·개봉 상태를 기록하고 날짜에 따른 확인 알림을 제공합니다.
- **소비·폐기 기록**: 처리한 수량만 차감하고, 조건에 맞는 마지막 처리는 취소할 수 있습니다.
- **개봉·미개봉 분리**: 개수 단위에서 먹고 남은 포장을 자동으로 나눕니다. 예를 들어 미개봉 3개에서 0.5개를 먹으면 개봉 0.5개와 미개봉 2개가 남습니다.
- **전체·일부 수정**: 현재 구매 항목 전체 또는 선택한 수량의 정보를 수정하고, 다른 음식으로 옮길 수 있습니다. 목록에서는 여러 구매 항목을 함께 합칠 수 있습니다.
- **요리 등록**: 사용한 재료를 차감하고 완성한 요리를 등록합니다. 재료 사용량과 요리 수량을 나중에 정정할 수 있습니다.
- **기록 조회**: 등록·수정·소비·폐기·요리 등의 이력을 검색하고 확인합니다. 소비 이력의 날짜는 실제 먹은 날이 아닌 앱에 기록한 시각입니다.

위 내용은 현재 코드 기준입니다. 운영 반영 상태와 검증 범위는 아래 문서에서 별도로 관리합니다.
