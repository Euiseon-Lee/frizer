### 이번 변경의 최종 동작

1. **소비와 개봉 수량**: 확실한 개수 단위만 자동 계산한다. 3개에서 0.5개를 먹으면 개봉 0.5개와 미개봉 2개가 남는다. 개봉일 기본값은 ‘날짜가 기억나지 않아’이며 소비일은 받지 않는다. 수량 재입력 중에도 날짜 초안을 유지한다. 상세 정책은 [수량 설계](ITEM_QUANTITY_DESIGN.md)를 따른다.
2. **전체·일부 수정**: 기본은 전체 수정이다. 일부 수정은 현재 잔량보다 적은 수량에만 적용하며 음식명·분류·단위를 잠근다. 탭을 바꾸면 입력과 합치기 선택을 초기화한다. 수량 선택만으로 분리하지 않으며 실제 변경이나 합칠 대상이 있어야 저장할 수 있다.
3. **수정 안에서 합치기**: 전체·일부 모두 기존 음식 그룹을 선택할 수 있다. 전체 수정은 현재 구매 항목만, 일부 수정은 분리한 수량만 옮긴다. 다른 구매 항목과 종료 항목을 함께 옮기지 않고 단위를 합산·환산하지 않는다. 목록 합치기는 기존 다건 동작을 유지한다. 상세 정책은 [이동·분리 설계](ITEM_MOVE_DESIGN.md)를 따른다.
4. **이력과 버튼**: 소비 분리 안내와 취소 아이콘의 배치를 정리하고 날짜가 앱에 기록한 시각임을 표시한다. 개별 구매 상세의 ‘나누자’를 제거하고 ‘수정하자’를 전체 너비로 표시한다. 단독 상세의 합치기·삭제 버튼 표시 조건은 유지한다.
5. **저장 오류 수정**: 잠긴 필드 전송에 숨겨진 분류 갱신 버튼 값이 섞이던 문제, 날짜 오류 후 분류 변경을 감지하지 못하던 문제, 합치기 토글 해제 시 음식명 초안 소실, 영구 알림 설정의 변경 오판을 수정했다. 검색 결과 없음 안내도 추가했다.
