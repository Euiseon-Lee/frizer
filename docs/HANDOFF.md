## 확정된 정책

- 개봉 상태 순서: 해당 없음(NOT_APPLICABLE) / 미개봉(UNOPENED) / 개봉함(OPENED) / 불확실(UNKNOWN). 출처와 무관하게 직접 선택하고 신규 기본값은 미개봉이다.
- 개봉함에서만 개봉일 입력 가능. 날짜가 없으면 실제 개봉일은 NULL, 처음 개봉함으로 저장한 서울 날짜를 opening_confirmed_at에 기록한다. 일반 수정 시 확인일은 보존한다.
- 개봉함 이외 상태에서는 개봉일·확인일을 비운다. 해당 없음에는 개봉 경과 알림을 적용하지 않지만 소비기한·냉동 관련 판단은 유지한다. 조리일/소분일 전용 필드는 추가하지 않는다.
- 경고 제외는 개별 구매 항목 단위이다. 지정일 당일까지 홈 경고/확인이 필요한 음식에서 제외하며 영구는 9999-12-31, 해제는 NULL이다. 소비기한·냉동일·보관 위치 변경 시 해제한다.
- 영구 적용 체크 시 날짜창에 9999-12-31 표시 및 비활성화, 해제 시 기존 입력 복원. 상세 문구는 ‘영구적으로 경고 알림 꺼짐’. 해제 버튼은 ‘알림 제외 즉시 해제하기’, 우측 정렬이다.
- 직접 냉동이고 냉동일이 소비기한 당일/이전인 경우 소비기한 경고 대신 냉동 경과 안내를 사용한다. 임의 소비기한 연장이나 식품별 안전기간은 만들지 않는다.
- 엑셀에서도 네 가지 개봉 상태를 지원한다. 경고 알림 제외 설정은 엑셀에서 받지 않는다. 기존 두 시트 양식 호환을 유지한다.
- 배포 전 엑셀 등록 이력과 새 fingerprint의 호환은 사용자가 명시적으로 범위에서 제외했다. 새 버전 등록 후 재업로드 중복 안내·확인 없는 재등록 차단만 유지한다. 과거 receipt를 삭제하지 않는다.
