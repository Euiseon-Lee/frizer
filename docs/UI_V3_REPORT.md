# 쪼코 UI 개편 — 2026-09-13

## 적용 범위

Spring Boot / Thymeleaf 구조를 유지하고 기존 음식 목록·등록·상세 화면을 개편했다.
홈(`/`)은 리다이렉트 대신 실제 요약 화면으로 변경했다. 음식 목록의 위치 필터와 기록 조회(`/history`)를 추가했다.
공통 헤더, 하단 내비게이션, 이력 행은 `templates/fragments/shell.html`에 모았다.
새 기록 조회는 history/controller, service, dao, dto 구조를 따른다.

## 디자인과 문구

- 중앙 최대 448px, 모바일 전체 너비, 크림 바탕과 흰 콘텐츠 영역.
- 크림 #FFF8ED, 갈색 버튼 #694730, 본문 #292522, 보조 #766E67.
- 실온 #F9EDCE, 냉장 #DDF2E6, 냉동 #DDEEFF, 전체 #F0E9F6.
- 카드 모서리 18~20px, 고정 캡슐 내비게이션과 safe-area 하단 여백.
- 캐릭터 안내는 짧은 반말. 기존 사용자가 지정한 입력 안내 문구는 유지했다.
- 보관 위치 선택과 필터 순서는 실온 → 냉장실 → 냉동실.
- 날짜 안내는 제목 아래에 16px 하단 간격. 추가 정보 구분선·보조 문구 제거, select 화살표 우측 여백 14px 유지.

## 실제 데이터와 연결

- 홈: 활성 재고 수, 위치별 개수, 소비기한 경과 음식, 소비기한이 오늘인 음식, 미입력 개수, 최근 기록 3개.
- 경과와 오늘 날짜는 서울 Clock 기준으로 구분한다. 유통기한을 소비기한으로 대신 사용하지 않는다.
- TOP 3 정렬과 임박 일수는 확정 정책이 없어 도입하지 않았다. 오늘인 음식을 전부 표시한다.
- 기록: 최신 100개, 한국 시간, 현재 음식명과 당시 행동·위치·수량. 기존 스냅샷에서 조회한다.
- 소비·폐기·이동·일괄 등록·물리 삭제 기능을 새로 구현하지 않았다.
- DB 변경 없음. 냉장실·실온 보관 시작일도 이번에는 추가하지 않았다.
- 냉동일 미상은 NULL 유지. 오늘 체크 시 날짜 입력, 수동 날짜 변경 시 체크 해제 유지.

## V3 사진

원본 지시서·매핑·체크섬은 `docs/ui-v3/`에 보관했다. 이전 사진 매핑은 사용하지 않는다.
25개 원본 PNG는 `src/main/resources/static/assets/choco/`에 복사했고 SHA256이 패키지와 일치한다.
`static/js/choco.js`에서 사진 풀을 관리하며 페이지 진입 시 한 번 선택한다. 입력 중 교체·타이머 슬라이드는 없다.

| 실제 연결 화면 | 사진 후보 |
|---|---|
| 고정 프로필 | profile |
| 홈 대표 | home-hero, happy-lounge, happy-sit, welcome-lounge |
| 실온 카드 | proud-sit, happy-sit |
| 냉장 카드 | leaf-hat-front, leaf-hat-side, flower-sniff |
| 냉동 카드 | happy-lounge, rest |
| 전체 음식 카드 | happy-closeup |
| 등록 화면·배너 | add-food, come-running, flower-sniff |
| 저장 성공 | success, happy-sit, gentle-pet |
| 기록·목록·상세 헤더 | look-back, look-aside |
| 첫 사용·빈 목록 | puppy-sit, empty-curious |
| 경과 안내 / 오늘인 음식 / 오늘인 음식 없음 | attention / sniff / rest |
| 오류 화면 | empty-curious |
| 풀에 준비했지만 화면 미연결 | relaxed-stretch, cheek-squish, playful, peek-upside-down |

홈에는 상태에 따라 보조 사진을 포함해 약 7~8장과 작은 프로필이 등장한다.
원본 얼굴·알파·귀·코를 보존하고 contain으로 표시한다. 손·잔디·매트·누끼 경계는 원본 그대로다.
사진의 크기 지정, 하단 lazy loading, 히어로 우선 로딩을 적용했다.
WebP 변환·리사이징·배경 보정은 수행하지 않았다. 원본 PNG 용량이 커 첫 방문 이미지 전송량은 후속 최적화 대상이다.

## 검증

- Gradle test 및 bootJar 성공: 123개 테스트(통합 26 / DB 97), 실패 0.
- 새 홈에서 경과/오늘/미입력 분리, 유통기한 대체 금지, 위치 필터, 실DB 기록 조회 검증.

- 320px 긴 음식명 목록·상세·경과 홈·기록 확인, 등록 성공 후 두 날짜와 수량·용량·출처 메모 보존 확인.
- 실제 기타 출처 입력, 실온/냉장 선택 시 냉동 입력 숨김, 오늘 체크/수동 날짜 변경 확인.
- 검증용 음식 ID 3과 해당 이력만 조건을 대조해 삭제했다.
- 로딩 오버레이는 SSR에 불필요하여 만들지 않았다. 오류 페이지는 실제 오류 응답으로 제공하며 핵심 내비게이션은 사진과 독립적이다.
- 커밋·푸시하지 않았다.
