# 쪼코 V4 적용 결과

2026-09-13. 갱신된 `choco-codex-kit.zip`의 `choco-codex-kit-v4`를 기준으로 반영했다.
원본 지시서·매핑·검수 목록·사진 풀은 `docs/ui-v4/`에 보관한다. UI_V3_REPORT는 과거 작업 기록이다.

## 변경

- A등급 16장만 서비스 정적 자산에 포함. 모든 파일 SHA256이 V4 매핑과 일치한다.
- 잔디 제외 사진 3장과 B등급 사진은 템플릿 기본 이미지, 자동 교체 풀, 정적 자산, 빌드 JAR에서 제외했다.
- 이전 정적 자산은 삭제 대신 무시되는 build/ui-v3-retired에 보관했다. 사용자 다운로드 원본 ZIP은 수정하지 않았다.
- 기본 홈 이미지 happy-lounge, 홈 교체 후보 happy-sit/proud-sit. 등록 come-running/puppy-ready/puppy-front-paws, 기록 look-aside, 프로필 happy-closeup.
- image-pools.json과 일치하는 A등급 후보만 자동 선택한다. 상태 입력 중 교체·타이머 없음.
- 초상 사진은 카드 하단, sniff는 왼쪽 경계에 붙인다. 전신 사진은 contain과 여백으로 발·꼬리를 추가로 자르지 않는다.
- B등급은 사용하지 않았다. 보정·새 신체 생성·이미지 색상 필터·WebP 변환은 수행하지 않았다.

## 테마

- 표면 흰색, 바깥 #F7F7FB, 제목·수치 #30313D, 보조 #696B7A.
- 실온 #FFF5CF / 냉장 #E3F6EC / 냉동 #E5F1FF / 전체 #F0E9FF / 등록 배너 #FFF0F5.
- 버튼 #7057C8, hover #6048B5, 흰 글씨. 기존 갈색 버튼·베이지 배너·카드별 유색 본문 제거.
- 히어로는 옅은 라일락 단색. 그라데이션 제거. 입력 포커스와 선택 강조도 보라색으로 통일.
- 주요 안내 글씨를 14px로 확대하고 제목·수치의 과한 굵기를 완화했다.

## 검증과 유지 사항

- 테스트 123개 통과, bootJar 성공.
- 사진 풀과 모든 템플릿 기본 이미지가 default_enabled=true인 A 파일에 연결되는지 대조했다.
- 빌드 JAR의 공개 사진 16개 확인.
- 홈 320/375/390/448/1024px 가로 넘침 없음, 데스크톱 본문 448px. 등록 320px 확인.
- 흰색 대비: 버튼 5.40:1, 본문 12.86:1, 보조 5.27:1.
- 보관 위치 순서, 두 날짜 선택 입력, 등록 버튼 화살표 제거 등 사용자가 확정한 사항 유지.
- 도메인·DB 변경 없음. TOP 3 정책과 냉장/실온 보관 시작일은 이번 범위에서 추가하지 않았다.
- 커밋·푸시 없음. PNG 전송량 최적화는 별도 작업으로 남아 있다.
