# V5 Final 적용 결과

2026-09-13. 최신 지시서와 사진 매핑은 docs/ui-v5/에 보관했다.

- A 16장을 패키지의 알파 경계 보정본으로 교체했고 SHA256 일치를 확인했다. 추가 보정이나 WebP 변환은 수행하지 않았다.
- B 사진과 잔디 제외 사진은 공개 자산·자동 후보에 포함하지 않는다.
- 히어로 #FAF8FF, 정상 안내·등록 배너는 흰 바탕. 사용자 후속 요청에 따라 두 영역에 얇은 테두리와 18px 둥근 모서리를 유지했다.
- ✳ 장식은 상단 8px로 이동. 320px에서 사진 요소와 48px, 375/390/448/1024px에서는 28px 간격을 확인했다.
- 보관 위치 4색과 보라색 주요 버튼 유지. 등록 배너는 happy-sit/proud-sit 별도 후보, 등록 입력 화면은 기존 A 후보를 유지한다.
- 최근 기록과 음식 기록 화면의 공통 배지에 이벤트 속성을 연결했다. 등록 민트·소비 살구·냉동 하늘·이동 회색·폐기 코랄 배경과 글자 토큰 적용.
- 미지의 이벤트 스타일은 중성 기본값으로 처리한다. 현재 DB/API는 기존 enum 계약을 유지한다.
- `.history-neutral-text`를 기록 컨테이너에 적용하면 배지 글자만 먹색으로 전환 가능하다. 사용자 설정 UI는 추가하지 않았다.
- 등록 화면 상단 버튼과 등록 버튼의 대각선 화살표 제거. 최종 문구와 배치는 아래 후속 정리를 따른다.

## 검증

- Gradle 테스트 123개 및 bootJar 통과. 이후 테두리만 조정하고 빌드를 갱신했다.
- 홈 320/375/390/448/1024px에서 가로 넘침 없음. 사진 간격과 정상 상태·등록 배너·실제 등록 배지의 브라우저 표시 확인.
- 5종 배지는 공통 CSS 토큰과 이벤트 속성 매핑으로 연결했다. 현재 실제 데이터에 있는 등록 배지를 시각 확인했다.
- 소비기한이 오늘인 음식만 노란 안내를 적용하고, 경과는 코랄 안내로 구분한다. 임박 일수·TOP 3 정책은 새로 만들지 않았다.
- UI 검증 과정에서 기존 사용자 재고 데이터는 변경하지 않았다. 원격 push는 진행하지 않는다.

## 사용자 후속 조정 및 최종 정리

- 하단 탭: 홈 / 뭐 있지? / 등록 / 기록.
- 홈 소개: 홈 프로텍터, 쪼코. 제목: 오늘 뭐 먹을 거야?
- 홈 섹션: 한눈에 보기 / 쪼코가 지키는 중! 최근 기록은 한 줄로 표시.
- 목록 상단: 쪼코랑 같이 찾아보자! / 우리 집에 뭐가 있더라?
- 등록 상단: 킁킁, 맛있는 냄새 / 음식 등록하자! / 쪼코가 기억해둘게.
- 기록 상단: 우리 집에 있던 음식들 / 다들 어디로 갔을까? / 쪼코랑 기록을 살펴보자!
- 세 탭 상단의 좌우 여백을 홈 히어로에 맞췄다.
- 목록 카드 왼쪽에 위치·출처, 음식명, 수량·용량을 배치하고 음식명·수량은 9px 들여쓴다.
- 카드 오른쪽에는 입력된 유통기한·소비기한을 각각 표시한다. 둘 다 없으면 기한 미입력으로 표시한다.
- 카드 전체가 상세 링크이며 hover·키보드 focus 상태를 제공한다. 별도 상세 보기 줄은 제거했다.
- 홈 하단: 쪼코와 함께 냉장고 파먹기. 목록 하단: 쪼코가 항상 지키고 있다구.
- 최종 검증 명령: `gradlew.bat test bootJar --no-daemon --console=plain`.
- 이전 경고 문구를 기대하던 통합 테스트를 현재 경과 안내 문구에 맞췄다.
