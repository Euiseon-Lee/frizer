# 쪼코 Codex 전달 패키지 V3

총 28장 중 25장 선별. 이번 추가 사진 9장 전부 포함, 이전 후보 중 16장 포함.
사용자 요청: 쪼코가 여러 화면에 자주 등장. 종전 9장/등장 제한 규칙을 변경한다.

1. ZIP을 Codex가 접근 가능한 프로젝트 폴더에 해제.
2. CODEX_PROMPT.md와 ASSET_MAPPING.md를 먼저 읽도록 요청.
3. assets/choco 안의 25개 PNG를 확인하고 image-pools 규칙에 맞춰 구현.
4. PREVIEW_01.jpg~PREVIEW_03.jpg는 사진 선별 확인용. 제품에 사용하지 않음.
5. asset-map.json에 실제 상대경로, 원본명, 치수, SHA256 포함.

사진은 이름만 변경한 원본 PNG. 투명 배경 유지. 보정이나 최적화 완료 파일이 아니며 일부 잔디·손·매트가 남는다. 신규 업로드 원본 28장은 삭제하지 않았다. 제외 3장 이유는 매핑 문서 참조.

전달 문장:
첨부 패키지의 CODEX_PROMPT.md와 ASSET_MAPPING.md를 읽고 쪼코 사진 25장을 화면별로 다양하게 사용해줘. V3의 빈번한 등장·사진 풀 교체 규칙이 이전의 사진 사용 제한보다 우선해.
