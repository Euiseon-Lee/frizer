# 쪼코 전체 이미지 검수·매핑 V4
총 41장(기존 28 + 추가 13) 검수. A는 우선 사용, B는 조건부·후순위, X는 제외.
자연스러운 얼굴 초상과 전신의 어색한 절단을 구분했다. 모든 A가 완전한 전신이라는 의미는 아니다. 경계가 애매한 사진은 B로 보수적으로 분류했다. 원본 PNG는 수정하지 않았다.
잔디/풀잎이 보이는 3장과 연락처 노출 1장은 ZIP에 넣지 않는다. B는 예비 자산으로 전달하지만 기본 자동 교체에서 제외한다.
