# 쪼코 V4 전달 패키지
41장 검수: A 16장 / B 21장 / X 4장. 사진 37장 포함.

- assets/choco: 우선 사용 사진
- reserve/choco: 잘림·구도 조건이 있는 후순위 사진 (자동 사용 금지)
- ASSET_MAPPING.md: 41장 전부의 원본명/용도/검수/제외 이유
- asset-map.json: 우선순위와 파일 매핑
- image-pools.json: 검수된 기본 화면별 교체 풀
- previews: A/B 검토용 미리보기. 제품 자산으로 사용하지 않음.
- CODEX_PROMPT.md: 잔디 제외와 V4 기준 구현 지시

기존 ZIP 위에 덮어 풀지 말고 이 V4 폴더를 기준으로 사용. 이전 9장/25장 제한을 적용하지 않는다. 원본 사진은 이름만 변경한 투명 PNG이며 이미지 보정은 하지 않았다. 소품인 잎 모자는 잔디 배경과 구분하여 유지했다.

Codex 전달 문장:
이 V4 패키지의 CODEX_PROMPT.md와 ASSET_MAPPING.md를 읽고 전체 UI에 적용해줘. 잔디 사진은 제외하고 A를 기본으로 다양하게 사용해줘. B는 문서의 조건부 배치만 허용하며 큰 사용 전에 확인해줘. 이전 사진 매핑과 자동 교체 풀은 V4로 대체해줘.
