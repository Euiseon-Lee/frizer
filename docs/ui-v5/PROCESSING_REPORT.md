# V5 가공 결과 — 투명도만 최소 수정

주력 A 16장은 경계 알파만 미세하게 낮추었다. 사진 RGB 값·캔버스 크기·자세·잘린 영역은 보존했다. 보조 B 21장은 가공하지 않았다. 잔디 제외 정책과 V4의 A/B/X 분류를 유지한다.

## 방법과 한계
불투명도 128 이상인 본체의 안쪽 2픽셀 경계 및 반투명 외곽에서만 기존 알파를 작은 비율로 낮춤. RGB 변경 0, 알파 확대 0. 얼굴·몸의 불투명 내부를 평활화하지 않음. 생성형 편집 결과는 채택/포함하지 않음.
흰/초록 프린지는 투명도 감쇠로 약하게 완화되지만 원래 RGB에 섞인 배경색을 제거한 것은 아니다. 굵은 배경 잔여·손·매트·잘린 신체를 복구하지 않았다. 특히 empty-curious의 왼쪽 깊은 패임은 실제 몸 외곽을 추정해야 하므로 남겨두었다. 완전 재누끼라고 표현하지 않는다.
사용자 요청대로 변경을 최소화했으므로 축소 미리보기에서는 차이가 작다. 썸네일 자체의 리사이즈는 검토용이며 배포 PNG의 크기는 원본과 같다.

## 밝기
밝기 보정은 이번에 적용하지 않았다. 사진 전체 평균을 동일하게 맞추면 사진마다 얼굴/몸통 비율이 달라 부적절해진다. 파스텔 화면에서 얼굴 디테일과 흰 털의 하이라이트를 기준으로 개별 조정하는 편이 적합하다.
추가 검토 후보: puppy-sit / puppy-tilt는 다른 밝은 사진과 나란히 놓으면 상대적으로 어둡고, empty-curious는 노란 조명이 더 강하다. 그렇다고 동일 노출값을 강제하지 않는다. 실제 배치 후 해당 사진만 소폭 검토한다. 현재 파일은 RGB를 정확히 보존한다.
