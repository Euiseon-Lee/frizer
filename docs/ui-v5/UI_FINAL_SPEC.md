# V5 Final — 화면 색상 및 기록 배지 확정 지시

이 문서는 이번 대화에서 합의한 최신 화면 지시다. 이전 핑크 등록 배너 및 넓은 유색 패널 지시를 대체한다. 실제 앱 수정본이 아닌 Codex 구현용 명세이며, 구현 후 화면 검증이 필요하다.

## 색의 역할
연보라 primary는 유지한다. 브랜드, 주요 버튼, 선택 상태, 동작 링크에 사용한다. 기록 종류 분류에는 primary 및 그 파생 토큰을 사용하지 않는다. 넓은 면의 색을 줄이고 보관 위치 4개 카드의 파스텔은 유지한다. 사진 노출 횟수를 줄여서 해결하지 않는다.

## 홈 영역별 적용
| 영역 | 최종 적용 |
|---|---|
| 헤더 | 흰색 유지 |
| 히어로 | 흰색에 가까운 매우 옅은 라벤더 #FAF8FF. 브랜드 보라 유지 |
| 오늘의 냉장고: 정상 | 흰 바탕에 작은 쪼코와 1~2줄 요약. 기존 회보라색 큰 둥근 패널 제거. 간결한 정보 행 구성 |
| 오늘의 냉장고: 주의 | 실제 소비기한 임박에만 노란 안내, 경과에는 코랄 안내. 정상·로딩·오류와 구분. 색 외에도 문구/아이콘 표시 |
| 보관 위치 | 현재 2×2 카드와 사진 구성 유지. 실온 #FFF5CF, 냉장 #E3F6EC, 냉동 #E5F1FF, 전체 #F0E9FF. 텍스트는 먹색 |
| 새 음식이 왔네! | 핑크·베이지·회색 채움 제거. 흰 영역 + 얇은 상단 구분선 + 보라 CTA. 높이와 불필요한 여백 축소. happy-sit/proud-sit 우선 |
| 하단 내비 | 흰 바탕, 보라 선택 상태 유지. 마지막 콘텐츠와 겹치지 않게 하단 여백 확보 |

제거한 색 면적을 다른 파스텔 패널로 다시 채우지 않는다. 쪼코는 홈 전체에서 6~8회 등장 가능하다. 등록 배너와 입력 화면의 사진 풀은 별도 관리한다.

## 최근 기록 및 전체 기록 공통 배지
| 이벤트 | 표시 | 배경 | 글자 |
|---|---|---|---|
| CREATE | 등록 | #E5F3EB | #286247 |
| CONSUME | 소비 | #FFF0DC | #85521D |
| FREEZE | 냉동 | #E5F1FC | #285F8F |
| MOVE | 이동 | #EEF0F3 | #505C6B |
| DISCARD | 폐기 | #FBE9E7 | #963E38 |

배지에만 작은 면적으로 적용하고 기록 행 전체를 색칠하지 않는다. 식품명 #30313D, 위치·수량·날짜 #696B7A. 전체 보기 같은 동작 링크는 보라 유지 가능하다. 이벤트 이름은 기존 API 계약을 유지하고, 미지의 이벤트는 중성 배지와 기존 안전한 라벨로 처리한다.

배경과 글자 토큰을 분리한다. 사용자는 글자까지 색을 바꿔야 하는지는 유보했지만 우선 위 조합을 적용하기로 했다. 추후 글자만 #30313D로 통일할 수 있도록 개발용 CSS 클래스 또는 속성 한 곳으로 전환 가능하게 한다. 사용자용 설정 화면은 만들지 않는다. design-tokens.css는 참고 구현이며 기존 스타일에 맞춰 이식한다. primary/보관 위치/기록/경고 토큰은 의미별로 독립시킨다.

## 적용과 검증
이 명세대로 구현을 진행한다. 화면의 임의 재배색이나 새 디자인 방향은 사용자와 논의한다. 통상적인 반응형 조정은 진행 가능하다. 모바일 320/375/390/448px 및 데스크톱에서 가독성, 버튼 대비, 사진·문자 겹침, 고정 내비 가림을 확인한다. 정상/임박/경과/빈 목록/로딩/오류 및 5가지 기록 배지를 확인한다. 음식 도메인 로직과 API는 유지한다.

사진은 ASSET_MAPPING.md와 PROCESSING_REPORT.md를 따른다. 잔디 제외, 잘린 사진 후순위, A 16장 알파 경계만 최소 수정, RGB·밝기 변경 없음. 원본의 잘린 신체를 생성하지 않는다.
